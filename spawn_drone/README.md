# spawn_drone (C++ / ament_cmake)

ROS 2 package that:

1. Launches the PX4 SITL x500 quadrotor with gimbal via
   `make px4_sitl gz_x500_gimbal`
2. Launches the MicroXRCE Agent (`MicroXRCEAgent udp4 -p 8888`)
3. Spawns the drone in a custom industrial-zone Gazebo world
   (`worlds/industrial_zone.sdf`)

## Build

```bash
cd ~/Desktop/argus/ros2_ws
source /opt/ros/jazzy/setup.bash
colcon build --packages-select spawn_drone
source install/setup.bash
```

## Run

```bash
ros2 launch spawn_drone spawn_drone.launch.py
```

Optional arguments:

```bash
ros2 launch spawn_drone spawn_drone.launch.py \
    px4_dir:=/home/ubuntu/Desktop/argus/PX4-Autopilot \
    world:=industrial_zone \
    model_target:=gz_x500_gimbal
```

The launch file copies `industrial_zone.sdf` into the PX4 `Tools/simulation/gz/worlds`
directory and sets `PX4_GZ_WORLD=industrial_zone` so PX4's Gazebo launcher picks it up.

## Worlds

| World | Description |
|-------|-------------|
| `industrial_zone` (default) | Procedural industrial estate (~410 m x 310 m), muted colours. |
| `industrial_zone_real` | Same layout, but buildings, cooling towers, power plant, water tower, tower crane, transformers, vehicles, lamp posts, poles and trees are real 3D models pulled from [Gazebo Fuel](https://app.gazebosim.org). Needs internet on first launch. |

```bash
ros2 launch spawn_drone spawn_drone.launch.py world:=industrial_zone_real
```

For Fuel-based worlds the launch file pre-downloads any missing models (PX4 only waits
~30 s for Gazebo) and adds the Fuel cache to `GZ_SIM_RESOURCE_PATH` so older Fuel models
find their textures. The real world is heavier to render than the procedural one.

Both worlds are generated by `tools/gen_industrial_zone.py`:

```bash
python3 tools/gen_industrial_zone.py worlds/industrial_zone.sdf
python3 tools/gen_industrial_zone.py worlds/industrial_zone_real.sdf --real
```
